# 📚 Book Manager - Frontend

A modern React + Vite frontend application for managing books with full CRUD operations.

## 🚀 Features

- ✅ View all books
- ✅ Add new books
- ✅ Update existing books
- ✅ Delete books
- ✅ Loading states
- ✅ Error handling
- ✅ Responsive UI
- ✅ Connects with custom backend API

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios / Fetch API
- JavaScript (ES6+)
